## 本轮回归发现并修复

1. 规划生成前查看风险后，风险摘要被误认为最新规划输入，导致导表/约束入口消失。现只按真正的规划输入结果定位。
2. Provider 与服务会话在开发 effect 重放中复用了已销毁实例。现由每次 effect 生命周期创建和清理实例，普通重渲染保留现有 store。
3. 新建会话或阶段交接的迟到响应可能覆盖用户刚切换的会话。现精确比较发起时选择，包括隐式选择 `null`。
4. 外观同步可能误处理 sessionStorage 同名事件。现仅接受 localStorage 与允许的外观字段。
5. 打开连接配置时重复发送引导消息可能重建正在填写的表单。现入口直接打开已有表单，当前回复未完成时暂禁用旧配置入口；连接失败重试实测保留输入。
6. 清理过期独立页断言、旧状态转发模块、专属分页/模式状态和未使用偏好事件代码；补齐规划时间线英文标识。
