# MigrationDirector Plus

迁移交付工作台的前端交互原型，用于设计和体验调研评估、规划设计、迁移实施、结果验证四个阶段。

## 项目如何运行

这是 Web 项目，源码需要通过开发服务编译，不能直接双击 `app/page.tsx` 打开。

```text
npm run dev
    ↓
Vinext / Vite 启动本地开发服务
    ↓
编译 React、TypeScript 和 CSS
    ↓
浏览器访问 http://localhost:3000/
```

技术栈为 React 19、TypeScript、Tailwind CSS 4。目录采用 Next.js App Router 的结构，但实际启动命令使用 **Vinext**，不是 `next dev`。

修改源码后，开发服务通常会自动更新页面。终端里的服务需要保持运行；退出服务后，本地地址就无法访问。

## 本地启动

环境要求：Node.js **22.13.0 或以上**，以及 npm。首次安装依赖需要联网。

首次获取代码并启动（macOS / Linux）：

```bash
git clone https://github.com/lyhlyhlyh233/migrationagentdemo.git
cd migrationagentdemo
npm ci
SITES_LOCAL_NODE_PREVIEW=1 npm run dev -- --host 127.0.0.1 --port 3000
```

已有源码时，直接进入项目目录，从 `npm ci` 开始执行即可。私有仓库克隆需要对应 GitHub 访问权限。启动后打开 [本地页面](http://localhost:3000/)。

- 依赖已经安装且锁文件没有变化时，可以跳过 `npm ci`。
- `SITES_LOCAL_NODE_PREVIEW=1` 会让配置跳过 Cloudflare 插件，使用本地 Node 模式预览；推荐本地开发时带上它。
- 本地原型无需配置模型 API Key 或数据库账号。
- 停止服务：在启动服务的终端按 `Ctrl + C`。
- 3000 端口已占用时，先查看已有页面，或将启动命令中的端口改为 `3001`，再访问对应地址。

Windows PowerShell 的启动写法：

```powershell
$env:SITES_LOCAL_NODE_PREVIEW = "1"
npm run dev -- --host 127.0.0.1 --port 3000
```

同样需要先进入项目目录并安装依赖。

## 构建与检查

以下命令均在项目目录执行：

```bash
# TypeScript 类型检查
npx tsc --noEmit

# 代码规范检查
npm run lint

# 构建本地 Node 模式产物
SITES_LOCAL_NODE_PREVIEW=1 npm run build

# 启动构建后的服务（需先构建；不要与开发服务占用同一端口）
SITES_LOCAL_NODE_PREVIEW=1 npm run start
```

开发阶段使用 `npm run dev` 即可，不需要每次都构建。`npm run start` 本身不负责构建，也不提供开发时的热更新。

## 当前原型的能力边界

- 项目、会话、风险和任务状态保存在当前页面的 React 内存状态中；项目之间切换会保留状态，刷新或重新打开页面会重置。
- AI 回复通过前端规则和预设文本生成，没有调用真实大模型。
- 评估、批次规划、MD 连接检查、执行进度及配置验证由示例数据和定时器模拟，不会执行真实迁移。
- 选择资料文件时主要记录文件名，没有上传服务器，也没有实现真实的 Excel 内容解析。
- 报告和表格下载由前端依据当前示例状态生成。
- 账户区域支持前端退出交互；Nexent 认证支持 API Key 和账号密码配置，尚未接入真实登录、令牌撤销或平台认证接口。
- 未接入真实业务后端、数据库或持久化存储；配置中的托管能力不等于业务已经接入这些服务。

后续正式实现时，需要将前端模拟逻辑替换为模型服务、迁移执行接口、文件解析、任务状态订阅及数据存储。

## 交付会话与阶段交接

- 左侧顺序：任务、风险、交付件、日志 → 四阶交付会话 → 临时对话。未选择项目时，四个资料入口不可点击，悬停显示「创建或选择项目后开启」。
- 交付会话列表保留各阶段的历史会话。创建项目时开启调研评估会话；后续阶段须人工确认交接，才自动创建新阶段会话。顶部已进入的阶段可直接切换，恢复该阶段最近打开的会话。
- 点击「四阶交付会话」旁的加号，在当前查看阶段新建会话。手动新建会话首次提问后自动命名，所有交付会话均支持重命名。
- 自动创建的阶段会话保留引导表单；其他会话通过输入框上方的分类快捷操作按需展开表单。
- 评估交接要求评估完成且评估高风险已闭环；实施交接要求规划完成且规划高风险已闭环；验证交接要求已有割接结果。交接区显示条件与影响，点击「确认进入…」后记录人工确认并创建新阶段会话。「暂不进入」保留现状。
- 每段会话独立保存消息、输入草稿、回复等待状态和展开的操作区；项目资料、任务、风险、交付件与执行进度共享，正在执行或已完成的操作不能重复启动。
- 对话输入框底部可选择 GLM 5.1（默认）或 DeepSeek v4，占位模型尚未接入真实服务。选择按会话保存，发送时记录本轮模型；切换只影响后续消息，新会话回到默认值。聊天正文不逐条显示时间，操作日志和右侧活动仍保留时间记录。
- 后台完成不会创建阶段会话或跳转，异步结果回到发起会话。右侧活动只展示当前会话记录，操作日志记录来源阶段、会话及人工交接。
- 管理页面与临时对话隐藏四阶。不同项目的数据独立，仅在当前页面会话中保留，刷新后重置；外观、背景和语言偏好仍保存在本地。


## 设置、账户与平台认证

点击左下角当前用户右侧的齿轮，打开右侧设置抽屉；左侧菜单折叠后，底部齿轮仍可直接打开设置。

抽屉宽度为 560px，窄屏适应页面宽度；「通用设置」集中管理外观、背景和语言，「账户与认证」提供当前用户退出及 Nexent 配置。

- 外观：白色（默认）、深色、青绿、酒红。
- 背景：纯色（默认）、白色曲面、雾中远山、石墨波纹。图片铺满整个工作台，贯穿左侧导航、中央页面和右侧详情；表单、表格与浮层保留清晰底色。图片随项目加载，来源见 [背景资源说明](public/backgrounds/README.md)。
- 语言：简体中文（默认）或 English。翻译导航、表单、任务状态和快捷操作等界面文案；新增助手回复按发起时的界面语言生成，已有聊天和用户填写内容保持原文。
- 三项偏好自动保存到当前浏览器；刷新、切换项目后仍生效。禁用浏览器存储时仍可即时切换，但刷新后使用默认值。
- Nexent 认证：选择 API Key 或平台账号密码，无需填写平台地址。认证方式带用途说明，输入框下展示规则；支持必填与 API Key 空白字符校验、凭据显隐、手动保存和清除配置。保存状态为「已配置 · 未验证」，不会发起网络认证或影响现有迁移流程。凭据仅保存在 React 内存，不写入浏览器存储、URL 或日志；关闭设置会丢弃未保存的输入，已保存配置在当前页面中跨项目共享。
- 退出登录：先展示清除范围，再由用户确认。退出后卸载工作台，清除本次页面的项目、会话和认证配置，保留外观、背景和语言偏好。退出状态页可重新进入空白工作台；刷新也恢复前端预览入口，不代表真实身份验证。
